# IoT-Based Bluetooth Controlled Robot 🤖

## 📌 Overview
This project is a high-speed Bluetooth-controlled robot built using ESP32. It can be wirelessly controlled via an Android application, making it suitable for robotics competitions and real-time control systems.

## 🚀 Features
- Bluetooth-based wireless control (ESP32)
- High-speed motor control using L298N motor driver
- Smooth acceleration using optimized PWM signals
- Precise directional movement (forward, backward, left, right)
- Low-latency communication for real-time response

## 🛠️ Components Used
- ESP32
- L298N Motor Driver
- DC Motors
- Chassis
- Battery Pack
- Android Bluetooth App

## ⚙️ Working
The ESP32 receives commands from an Android app via Bluetooth and processes them to control motor direction and speed using PWM signals through the L298N driver.
